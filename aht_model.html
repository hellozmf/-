为什么"再加几个工作流方案"不够 · 守恒律

系统中 S1-S5 五个方案里,S1/S2/S3/S4 是工作流优化——改变核查工作的执行位置,但不改变工作总量。具体来说:

  • r₂/r₃ 互补保护:总审跳过核查(r=0)→ 终审必须做(r'=1);总审做核查(r=1)→ 终审省事(r'=0)。核查工作总量守恒,只是从一个环节转到另一个。
  • α 通道(跳过总审)直送终审:这部分报告必须由终审医生完整核查(r₂'=r₃'=1),无法被 μ 释放。
  • 双审报告(两个环节都过眼)= (1−α)·(1−μ),里面有不可消除的 ρ·ρ' 底盘。仅靠 r₂/r₃ 不能消除任何一项双审。

§01 关键结论

差距明确:总审 −50%,终审 −52%。守恒律确立:仅靠 r₂/r₃ 的位置切换,任何情景下总审与终审都不能同时 ≤ 1 min——这就是守恒律的直接证据。需要新杠杆:除了位置切换,还需要 ρ/ρ' 总量削减 + P/P' 双审消除。三类杠杆同时推动才有解 → §02。

§ 02三类杠杆 · 本质区别

从"再加几个方案"思路升级为"三类杠杆同时推",每类对应的工程行动完全不同。

对照表 · 三类杠杆

类别 参数 业务杠杆 作用机制 对总工作量 典型 ROI
位置 杠杆 r₂ / r₃ 核查工作放总审 vs 终审 0/1 二值开关,互补保护 守恒不变 局部提效 / 体感优化
总量 杠杆 ρ / ρ' AI 报告 / 终审实际改判率 减少需要改判的报告总数 总量下降 ρ 0.30→0.20 节省 0.22 min

位置杠杆 · r₂/r₃ 互补保护(必要不充分)

r₂/r₃ 只有 0 / 1 两个值,决定核查在哪个环节做:

  • α 通道(总审跳过):终审强制 r₂'=r₃'=1 做完整核查
  • (β+γ) 通道(总审审过):终审 r₂'=1−r₂, r₃'=1−r₃ 取反,核查只由一方做

核查工作量恒等式:r₂ + r₂' = 1,r₃ + r₃' = 1。无论 r 值怎么变,总核查工作量恒定——这就是为什么单纯调 r 不能让总审/终审同时降下来。但 r₂/r₃ 仍然有价值——它把工作分配到"医生体感最不疲劳"的位置(终审做专一核查,总审跑流水线)。

总量杠杆 · ρ / ρ' 减少改判量(高 ROI)

γ = ρ·R(总审改判),γ' ≈ ρ'(终审改判)。降 ρ 和 ρ' 直接减少需要改判的报告总数——这是消除工作量,不是搬移。

  • 降 ρ 的杠杆:S5 · AI 报告质量优化(提示词迭代 + 模型升级 + 大量 case 训练)
  • 降 ρ' 的杠杆:① 自然受 ρ↓ 影响(理论链路);② 终审 AI 辅助(类比 S1 但作用于终审环节)
数值示例(默认 r=0):
  ρ = 0.30 → γ·t_C = 0.30 × 2.23 = 0.67 min(总审 AHT 主要部分)
  ρ = 0.20 → γ·t_C = 0.20 × 2.15 = 0.43 min
  节省 0.24 min · 杠杆系数极高

双审消除杠杆 · P / P' 消除模型误差(中 ROI)

双审报告 = (1−α)·(1−μ),展开为 4 项之和:

双审 = ρ·ρ' + ρ·FP' + FP·ρ' + FP·FP'

只有 ρ·ρ' 是"理论必然双审"(两个环节都确认要改的真改判,合理双审);其余三项都是模型误差导致的无谓双审,推 P 和 P' 接近 1 即可消除。

§02 关键结论

r₂/r₃ 是位置工具(必要不充分),ρ/ρ' 是总量工具(消除工作),P/P' 是双审消除工具(消除模型误差)。三类杠杆映射到不同团队的不同 ask——配置 ② 靠算法迭代,配置 ③ 靠终审产品创新,配置 ④ 靠 AI 报告团队持续。这就是 §04 跨部门协作矩阵的基础。

§04 关键结论

"双 1 min"是 5 个团队的 critical path 项目,任何一个团队不到位都会拖累整体。建议跨部门联合推进(而不是某个部门主导)。每个阶段的 KPI 已与团队绑定,可作为季度 OKR 输入。详细风险与卡点见 §05。

§ 05风险与卡点

6 个关键卡点 · 按风险等级排序 · 每个关联具体 owner 团队和缓解机制。
BLOCKER · 01 · 文化 HIGH

医生信任建立(r₂ 这一参数)

r₂ 是整个系统最脆弱的参数——医生敢不敢真的跳过对正常条目的核查,取决于他在心理上信任 S1 多深。这件事不能靠说服,只能靠经验性证据。

Owner:临床培训 + 算法团队(提供影子运行证据)

影响:r₂ > 0.30 时系统无法稳健达到 1.0 min。最大的工程风险所在。

缓解机制 影子运行 4–8 周展示 S1 零误差记录;在审阅 UI 上显性化"S1 已认证 X 项"标记;同步推进责任结构调整作为制度兜底。三件事必须同步,缺一不可。
BLOCKER · 02 · 政治 HIGH

责任结构调整

医生敢跳过核查不只是信任 AI,更需要在制度上明确"出了事不只是我担责"。这需要医务部、合规部、法务部联合出文件,明确"按协议操作 + 系统监控合格"前提下的责任归属。

Owner:合规法务(主) + 跨部门协调(联席)

影响:制度未调整,即使 S1 完美,r₂ 永远压不下去——这是文化卡点的制度基础。

缓解机制 项目启动时同步推进跨部门沟通;以 S2 高置信 + S4 分级 + 关键发现白名单作为完整合规框架;先以"批量确认"形式过渡(医生看列表统一签字),让责任在形式上仍保留。
BLOCKER · 03 · 监管 MEDIUM

合规对"模型跳过总审"的接受度

S2 高置信跳过总审在医疗场景的合规可接受性,需要前置论证。即使技术上有 99% 召回率 + 关键发现白名单双重保护,合规部门可能仍要求"每份报告必须经医生眼"。

Owner:合规法务

影响:如不接受,α 无法实现 → 总审 AHT 直接回落到 1.4+ min。

缓解机制 前置法务沟通,准备完整安全数据;以"批量确认"作为过渡形态——医生不逐份审阅,而看 10–20 份的列表统一签字,在法律意义上仍保留"医生过眼"。
BLOCKER · 04 · 技术 MEDIUM

S2 / S4' 模型精度不及预期

首版 S2 模型实际精确率可能低于建模假设的 0.75。S4 终审改判预测模型首版同样可能 P' < 0.75。如果模型达不到预期,α/μ 不能推到目标值,工程上的"双 1 min"路径阻塞。

Owner:算法团队

影响:模型表现可控但有不确定性,需要预留兜底空间。

缓解机制 影子运行 4–8 周实测精确率,达不到 0.70 时启动算法迭代;不能纸面假设 P 值;持续标注高质量训练数据。
BLOCKER · 05 · 流程 MEDIUM

终审 1 min 是结构性瓶颈

S2 跳过 50%+ 报告直送终审 + S1/S3 核查后置到终审,会让终审工作量显著增加。即便 S4 终审改判预测模型 P' 优化到 0.85,μ 释放也只能达到 1−ρ' = 0.72 上限(ρ'=0.276),终审 AHT 仍难压到 ≤ 1 min。

Owner:终审产品(主) + AI 报告产品(降 ρ' 联动)

影响:终审环节是 critical bottleneck;双 1 min 没有"近期可达"方案,只能长期推进。

缓解机制 ① 把 ρ' 从 0.276 显著降低(依赖 ρ↓ 联动 + 终审环节本身的 AI 辅助);② S4' 的 P' 推到 0.85+ 让 μ 接近其理论上界 1−ρ';③ 终审工作流深度重构(分级单审 + 工具优化);④ 接受"双 1 min"是长期目标。
BLOCKER · 06 · AI 生成 LOW

r₄ / AI 生成质量自然迭代

S1-S4 工作流方案未直接攻击改判操作时间(r₄)。r₄ 只能依靠 S5(AI 生成质量提升)带来的改判项数下降而间接降低。如果 S5 不同步推进,r₄ 维持 1.0,影响有限。

Owner:AI 报告产品(S5)

影响:r₄ 维持 1.0 时,总审 AHT 上升约 0.06 min,接近无影响。

缓解机制 AI 生成模型纳入持续迭代;如生成质量提升不显著,补 P0-2 工具优化(前端 1 人月)直接攻击 w₄。这是相对低风险的"加 0.10 min 安全边界"动作。
§05 关键结论

数学上五方案在乐观参数下(P ≥ 0.80, r₂ ≤ 0.15, P/P' 至 0.95)可达成总审 1 min;终审 1 min 在 ρ' ≤ 0.15 + 责任结构调整完成的前提下可达。工程上的不确定性主要不在数学,而在文化、政治、监管三件事是否同步推进——HIGH 风险卡点(医生信任 + 责任结构)的难度,可能比加 P0-2 或 P1-2 更高。建议:① 算法 + 临床 + 合规联合启动;② 文化卡点不靠"说服"而靠"影子运行数据";③ 接受"双 1 min"是长期项目,不是季度任务。

突破路径(再次确认):① 降 ρ'(从 0.276 下探)→ 减少 γ' 重时间权重;② 提 P' → 让 μ 接近上界;③ 推 ρ↓(S5,AI 报告质量)→ 同时降低总改判量与 ρ'。仅调 P/μ 等参数不能突破结构上界,必须从源头 ρ/ρ' 下手。

终审 r'r₂/r₃ 互补取反
双 AHT都 ≤ 1 min 才达成
混淆矩阵到 α/β/γ 的完整推导
问题背景

S2 总审改判预测模型对每份 AI 报告做一次二分类预测:这份报告医生会改判 vs 不会改判。预测结果决定:报告是否要进入总审环节、医生在总审里的工作量预期、是否能直送终审。

所有 28,706 份报告按"医生实际是否会改判"和"模型是否预测会改判"两个维度,可分为 2×2 = 4 类——这就是机器学习中的混淆矩阵(Confusion Matrix)。理解这四类的分布,是理解 α/β/γ 三种处理方式占比的关键。

2×2 混淆矩阵 · 直观对照

把所有报告按"实际 × 预测"的真值四象限填入下表:

预测:会改判 预测:不会改判
实际:会改判 TP 真阳
模型猜中了		 FN 假阴
漏判(临床风险)
实际:不会改判 FP 假阳
误报(增加审核量)		 TN 真阴
正确放行
四个量的计算

用三个参数 ρ(实际改判率)、R(召回率)、P(精确率)可完整推出四个量:

TP = ρ × R
FN = ρ × (1 − R)
FP = TP × (1 − P) / P
TN = (1 − ρ) − FP

直观理解:实际改判的报告占比为 ρ,其中 R 比例被模型识别(TP),剩下 (1−R) 漏掉(FN)。模型的精确率 P 定义为"预测会改判中真的会改判的比例",反推出 FP = TP×(1−P)/P。最后剩余的就是 TN。

三类报告的业务归宿(S2 按预测路由,本模型 v2 修订)

α 跳过总审 = TN + FN · 耗时 0 min

S2 预测"不会改判"的所有报告(包含 TN 正确预测 + FN 漏判)统一跳过总审,直送终审。注意:FN 报告虽然实际需要改判,但 S2 把它当作"不改"放过去了,临床上由终审兜底抓回(R 不能太低就是这个原因)。

β 快速确认 = FP · 耗时 t_B

S2 预测"会改判"但实际不会改。医生进入总审,扫一眼后快速通过。这是模型精度不够带来的"白看"工作,耗时 t_B ≈ 0.5–1.0 min。P 越高,FP 越小,白看越少。

γ 改判处理 = TP · 耗时 t_C

S2 预测"会改判"且实际真要改的报告。这是总审改判的主力,耗时 t_C ≈ 2.0–3.5 min。γ = TP = ρ·R,与 ρ 几乎成正比(因 R 接近 1)。

汇总公式(本模型 v2)
α = TN + FN → 跳过总审(含漏判)
β = FP → 快速确认
γ = TP → 总审改判

α + β + γ = TN+FN+FP+TP = 1 ✓
三个非直觉的关键洞察

① γ ≈ ρ·R,降 γ 要降 ρ。S2 模型本身减少不了改判量,只决定改判量的处理方式(精准识别 vs 误报)。要降低 γ,必须从源头——AI 报告质量(S5,降低 ρ)着手,而不是优化 S2。

② P 只决定 α 和 β 的分配。P 升高意味着 FP 缩小,β 收缩,把原本"白看"的报告挪到 α。但 (α + β) 之和(即"实际不会改的报告"加上漏判部分,接近 1 − ρ·R)基本恒定。

③ R 是临床安全底线,且通过 FN 影响终审 AHT。R 太低 → FN 大 → α 通道里漏判多 → 终审必须抓回并改判 → 终审 AHT 上升。R 既是纯安全约束(终审 R' 失误就签发了),又是效率约束(总审 R 失误推高终审 AHT)。

一个数值示例

取 ρ=0.30, R=0.99, P=0.75:

TP = 0.30 × 0.99 = 0.297
FN = 0.30 × 0.01 = 0.003
FP = 0.297 × 0.25 / 0.75 = 0.099
TN = (1 − 0.30) − 0.099 = 0.601

α = TN + FN = 0.604(60.4% 跳过总审,含 0.3% 漏判)
β = FP = 0.099(9.9% 快速确认)
γ = TP = 0.297(29.7% 总审改判)

含义:每 100 份报告,60 份跳过总审(其中含 0.3 份漏判,由终审抓回),10 份扫一眼通过,30 份总审改判。总审 AHT = 0×α + 0.099×t_B + 0.297×t_C。

问题背景 · 终审环节为何也需要混淆矩阵?

终审环节(S4 终审改判预测模型 + 分级单审制度)与总审环节本质同构——都是"分类预测 + 分流处理"的复合流程。终审 S4 对每份进入终审视野的报告做一次预测:这份报告会被终审医生改判 vs 不会改判。预测高置信"不会改"的部分被释放(总审单审通过,不进终审),其余进终审。

由于终审 S4' 在临床决策链的最后一环——没有下游兜底,所以终审的混淆矩阵不只是效率指标,更是纯质控指标:终审漏判 = 直接签发给用户 = 临床事故。

关键差异 · 建立在 (β+γ) 通道上,不包含 α 通道

终审混淆矩阵的分母不是全部报告,而是"总审审核过的报告"(β + γ 通道,占全部报告 1−α 比例)。原因:

  • α 通道(总审跳过的报告)统一进入终审,在终审做完整核查(r₂'=r₃'=1 强制),不允许被 μ 释放——因为它们没经过总审过眼,临床上不允许两端都跳。所以 α 通道不参与终审 S4' 的"释放决策"分类。
  • 只有 (β+γ) 通道的报告才进入终审 S4' 的预测分类:释放 / 一次过 / 改判。

这种"建立在子集上"的设计也是 μ = TN' 推导的前提。

2×2 终审混淆矩阵 · 直观对照

把 (β+γ) 通道的报告按"实际 × 终审 S4' 预测"的真值四象限填入下表:

S4' 预测:会改判 S4' 预测:不会改判
实际:会改判 TP' 真阳
→ γ' 终审改判		 FN' 假阴
→ 漏判,直接签发(事故!)
实际:不会改判 FP' 假阳
→ β' 终审一次过		 TN' 真阴
→ μ 释放,不进终审
四个量的计算(与总审同形式)

用三个参数 ρ'(进终审报告中的实际改判率)、R'(终审 S4' 召回率)、P'(终审 S4' 精确率)推出:

TP' = ρ' × R'
FN' = ρ' × (1 − R')  ← 终审漏判,纯质控
FP' = TP' × (1 − P') / P'
TN' = (1 − ρ') − FP'

注:ρ' 默认 = 0.276,是 BI 实测值(2026-04~05),代表"整体进终审报告"的实际改判率。建模时把它当作 (β+γ) 子集内的改判率使用,这在 FN 极小(≈ 0.3%)时是 mild 简化,工程上可接受。

三类报告的业务归宿(终审 S4' 按预测路由,占全部报告)

α' 免终审 = (1−α) × TN' · 耗时 0 min

终审 S4' 高置信预测"不会改判"且实际不会改的报告,由总审单审通过签发,μ = TN' 即释放比例。这是终审环节创造价值的核心——把"显然不会改"的报告从终审挪走,把医生时间释放给真正需要把关的报告。

β' 终审一次过 = (1−α) × FP' · 耗时 t_B'_βγ

终审 S4' 预测"会改判"但实际不会改。终审医生进入终审界面,扫一眼后快速通过。这部分是"终审白看",耗时 t_B'_βγ ≈ 0.5–1.0 min(取决于 r₂'/r₃')。P' 越高,FP' 越小,终审白看越少。

γ' 终审改判 = (1−α) × (TP'+FN') ≈ (1−α) × ρ' · 耗时 t_C'_βγ

终审 S4' 涉及实际会改的报告(TP'+FN' ≈ ρ')。这是终审改判的主力,耗时 t_C'_βγ ≈ 2.2–3.5 min。γ' ≈ (1−α)·ρ',与 ρ' 几乎成正比(因 R' 接近 1)。

汇总公式
α' = (1−α) × TN'  → 免终审 (μ 释放)
β' = (1−α) × FP'   → 终审一次过
γ' = (1−α) × (TP'+FN') ≈ (1−α)·ρ'  → 终审改判

α' + β' + γ' = 1 − α  ((β+γ) 通道占比)

α 通道(占比 α)单独进终审做完整核查,不在 S4' 分流之内
四个非直觉的关键洞察(与总审对比)

① R' 是纯质控,比 R 更严格。总审 R 失误还有终审兜底;终审 R' 失误就是"漏判直接签发给用户" = 临床事故。所以 R' 推荐 ≥ 0.995(总审 R ≥ 0.99 即可)。

② μ 的上限 = 1 − ρ'。即便 P'=1(完美精度),FP'=0,μ 最大也只能达到 TN' = 1−ρ'。当前 ρ'=0.276 时,μ 上限 = 0.724。要进一步抬 μ,只能降 ρ'。

③ ρ' 不是独立参数,理论上受 ρ 影响。AI 报告质量提升(ρ↓)→ 全流程报告质量改善 → 终审看到"需要改"的报告减少 → ρ'↓。本模型为简洁起见假设 ρ' 独立不变;实际工程上,优化 S5(降 ρ)应同步带动 ρ' 下降。

④ 与总审 α/α' 的语义差异。总审 α(跳过总审)是"S2 预测不改 + 直送终审";终审 α'(免终审)是"S4' 预测不改 + 总审单审通过签发"。两者结构同构,语义不同——总审 α 走向终审,终审 α' 走向用户。

一个数值示例

取 ρ'=0.276(BI 实测), R'=0.995, P'=0.75:

TP' = 0.276 × 0.995 = 0.2746
FN' = 0.276 × 0.005 = 0.00138(终审漏判率 ≈ 0.14%)
FP' = 0.2746 × 0.25 / 0.75 = 0.0915
TN' = (1 − 0.276) − 0.0915 = 0.6325

μ = TN' = 0.633((β+γ) 内 63.3% 可释放)
β'/(β+γ) = FP' = 0.092(9.2% 终审一次过)
γ'/(β+γ) ≈ ρ' = 0.276(27.6% 终审改判)

若 α=0.60,则对全部报告:

α' = (1−0.60)·0.633 = 0.253(25.3% 免终审)
β' = (1−0.60)·0.092 = 0.037(3.7% 终审一次过)
γ' = (1−0.60)·0.276 = 0.110(11.0% 终审改判)

α 通道 = 60.0%(强制进终审做完整核查)
进终审报告占比 = 60% + 3.7% + 11.0% = 74.7%
P' 的边际效应 · 直接抬 μ

P' 从 0.75 提到 0.95(其他参数不变):

P'=0.75 → FP' = 0.092, μ = 0.633
P'=0.95 → FP' = 0.0145, μ = 0.710

μ 上升 = 0.077(7.7 pp)
每 100 份 (β+γ) 报告多释放 7.7 份免终审

这就是 §02 中"4 杠杆"分析里 P' 的具体作用——它通过缩小 FP' 直接放大 μ,从而压低终审 AHT。
